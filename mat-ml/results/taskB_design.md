
## Addendum, 2026-10-04 (after the run; the design above is unchanged)
The sensitivity run showed that the 'upper' and 'two_sided' rules select identical rows for `binding_energy_zscan` (9,993 bilayers; no positive value lies below the lower bound),
so the sentence above saying that a two-sided rule would also delete genuine weak binders is NOT supported by this dataset for that target. For `distance` the rules differ
(two-sided also removes 109 gaps below 1.49 A: 10,080 bilayers kept). Results for both are reported; the 'upper' rule remains the primary one as registered.
